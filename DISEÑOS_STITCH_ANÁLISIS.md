## 📊 Análisis de Pantallas por Diseño

Cada uno de los 13 diseños incluye estas 4 pantallas:

### **Portada**
- Principal landing page
- Noticias destacadas (hero section)
- Últimas noticias
- Sidebar con categorías/widgets
- Altura: 2000-6488px (varía por diseño)

### **Artículo**
- Vista individual de artículo
- Título grande, imagen destacada
- Cuerpo de texto formateado
- Metadata (autor, fecha, categoría)
- Artículos relacionados
- Altura: 4300-7832px (contenido largo)

### **Categorías**
- Listado de categorías disponibles
- Grid o lista de categorías
- Descripción de cada categoría
- Altura: 2972-4168px

### **Sección Nacional**
- Vista de una categoría específica (Nacional)
- Artículos filtrados por categoría
- Sidebar, filtros
- Altura: 3034-5590px

## 💡 Recomendaciones por Tipo de Sitio

### Para sitios de **análisis profundo** → **The Observer** o **Nova News**
- Excelente para artículos largos
- Altura permite contenido extenso
- Enfoque en texto y análisis

### Para sitios **económicos/financieros** → **The Daily Ledger** o **The Metropolitan**
- Profesional y confiable
- Diseño formal
- Bueno para tablas y datos

### Para sitios **políticos** → **The Vanguard** o **The Continental**
- Audaz o elegante
- Adecuado para contenido serio
- Tipografía fuerte

### Para sitios **generales/versátiles** → **Aura**, **Neo-Focus** o **Mi Sitio Noticias**
- Minimalista y limpio
- Fácil de personalizar
- Funciona para múltiples géneros

### Para sitios **tradicionales** → **Chronicle News** o **Heritage**
- Inspiración editorial clásica
- Formal y profesional
- Respetable

Una vez exportados desde Stitch, personalizar:

1. **Logo/Branding** → Cambiar logo en header
2. **Paleta de colores** → Usar CSS variables para temas
3. **Tipografía** → Ajustar font-family por sitio
4. **Contenido** → Reemplazar textos demo con contenido real
5. **URLs** → Actualizar links a dominio correcto
6. **Meta tags** → SEO personalizado por sitio
