# Mega Prompt: Generacion de Logos para NexoPress Network

## Prompt Base Universal

```
Eres un disenador grafico senior especializado en identidad de marca para medios de comunicacion digitales. Tu estilo es sobrio, profesional y contemporaneo. Disenas logos que funcionan perfectamente en:
- Headers de sitios web (150-200px de ancho)
- Favicons (32x32 y 180x180)
- Redes sociales (avatar circular)
- Versiones monocromaticas (blanco sobre oscuro y viceversa)

REGLAS ESTRICTAS:
1. NUNCA uses gradients en el logo principal (solo colores solidos)
2. NUNCA incluyas fondos en el archivo de logo (fondo transparente PNG o SVG)
3. El logo debe ser LEGIBLE a 32px de altura
4. Debe funcionar en blanco y negro sin perder identidad
5. Evita elementos genericos (globos terraqueos, antenas de radio, papeles de periodico tradicionales)
6. Prioriza simbolos abstractos o tipograficos sobre ilustraciones literalistas

ESTILO VISUAL DE LA RED:
- Geometria limpia, lineas precisas
- Tipografia sans-serif condensada o semi-condensada para nombres largos
- Simbolos que sugieran el concepto sin ser obvios
- Paleta de 1-2 colores maximos por logo
- Espaciado generoso y proporciones aureas
```

## Instrucciones de Uso

### Opcion A: DALL-E 3 / ChatGPT
1. Copia el prompt base + el prompt especifico del sitio
2. Agrega al final: "Genera 3 variantes en fondo blanco y 3 en fondo negro. Entrega como PNG transparente 1024x1024."
3. Pide despues: "Ahora genera una version simplificada para favicon (solo el simbolo, sin texto) 512x512"

### Opcion B: Midjourney v6
1. Usa la estructura: `[Prompt especifico] --style raw --s 50 --ar 1:1 --no gradients background`
2. Para variaciones: `--sref [URL de referencia]` para mantener consistencia

### Opcion C: Designer Humano
Entrega este documento a un disenador con:
- Los 25 prompts especificos
- El archivo `sites-config.json` con los colores exactos de cada sitio
- Las reglas estrictas de la seccion "REGLAS ESTRICTAS"
- El requisito de entregar: PNG transparente + SVG editable + favicon.ico

## Checklist de Calidad del Logo

Para cada logo generado, verifica:
- [ ] Se ve bien a 32x32px (favicon)
- [ ] Se ve bien a 1024x1024px (social)
- [ ] Funciona sobre fondo blanco
- [ ] Funciona sobre fondo negro
- [ ] Version monocromatica es reconocible
- [ ] Simbolo separable del texto (funciona solo como icono)
- [ ] No usa gradients
- [ ] Usa los colores de la paleta asignada
- [ ] Tipografia es legible
- [ ] No es confundible con otro medio de comunicacion existente
